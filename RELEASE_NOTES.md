# ScreenLoop Developer Preview

Initial independent ScreenLoop release candidate.

## Highlights

- Local-first replay buffer recorder for Windows.
- Always-on display capture mode.
- Local clips library with favorites.
- Storage auto-manage that only deletes ScreenLoop-created, non-favorite captures.
- Video quality presets plus custom encoder and codec selection.
- Clip compacting with CPU SVT-AV1 support through FFmpeg/libsvtav1.
- Reworked app identity, icon, docs, and release workflow naming for ScreenLoop.

## Removed

- Account/login surfaces.
- Upload/cloud sharing surfaces.
- Game detection and game integrations.
- Cloud AI highlight generation.
- Old fork branding and frontend template docs.
